# Lab 02 — S3: Buckets & Objects

**Duration:** ~15 min  
**Goal:** Create S3 buckets, upload/download files, and explore the S3 API locally.

---

## Prerequisites

Make sure Floci is running and your environment is configured:

```bash
eval $(floci env)
echo $AWS_ENDPOINT_URL   # should print http://localhost:4566
```

---

## Part A — Buckets

### Create a bucket

```bash
aws s3 mb s3://workshop-bucket
```

### List all buckets

```bash
aws s3 ls
```

### Create a few more

```bash
aws s3 mb s3://raw-data
aws s3 mb s3://processed-data
aws s3 ls
```

---

## Part B — Upload Objects

### Upload a string directly

```bash
echo "hello, floci!" | aws s3 cp - s3://workshop-bucket/hello.txt
```

### Upload a local file

```bash
echo '{"user":"alice","action":"signup"}' > event.json
aws s3 cp event.json s3://workshop-bucket/events/event.json
```

### Upload a whole folder

```bash
mkdir -p sample-data
echo "row1" > sample-data/file1.csv
echo "row2" > sample-data/file2.csv
aws s3 cp sample-data/ s3://workshop-bucket/sample-data/ --recursive
```

---

## Part C — List & Download

### List objects in a bucket

```bash
aws s3 ls s3://workshop-bucket --recursive
```

### Download a single file

```bash
aws s3 cp s3://workshop-bucket/hello.txt ./downloaded.txt
cat downloaded.txt
```

### Download a folder

```bash
aws s3 cp s3://workshop-bucket/sample-data/ ./local-copy/ --recursive
ls ./local-copy/
```

---

## Part D — Metadata & Presigned URLs

### Get object metadata

```bash
aws s3api head-object \
  --bucket workshop-bucket \
  --key events/event.json | jq .
```

### Generate a presigned URL

```bash
aws s3 presign s3://workshop-bucket/hello.txt --expires-in 3600
```

> 💡 Floci honours presigned URLs locally — paste the URL into your browser or `curl` it.

---

## Part E — Delete Objects & Buckets

### Delete a single object

```bash
aws s3 rm s3://workshop-bucket/hello.txt
```

### Delete all objects in a bucket

```bash
aws s3 rm s3://workshop-bucket --recursive
```

### Delete the bucket

```bash
aws s3 rb s3://workshop-bucket
```
